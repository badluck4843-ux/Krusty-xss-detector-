# Krusty XSS Detector - Ethical

Detector educativo de XSS para labs autorizados. Solo uso ético.

## ⚠️ Uso Ético
Solo para sitios propios o con autorización. El uso no autorizado es ilegal.

## Cómo usar
1. Agrega tu dominio de prueba a `allowed_domains.txt`
2. pip install requests
3. python main.py
